# Neovim Configuration

## Requirements

- [Neovim](https://neovim.io/) 0.12+
- [tree-sitter CLI](https://github.com/tree-sitter/tree-sitter) — required by nvim-treesitter to compile parsers
- [ripgrep](https://github.com/BurntSushi/ripgrep) — required by Telescope for live grep

### Arch Linux

```
sudo pacman -S neovim tree-sitter-cli ripgrep
```

### macOS

```
brew install neovim tree-sitter ripgrep
```
